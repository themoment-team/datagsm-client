# DataGSM OpenAPI SDK Java / Kotlin

### 개요

**DataGSM OpenAPI SDK Java**는 DataGSM API를 Java 및 Kotlin 애플리케이션에서 쉽고 안전하게 사용할 수 있도록 설계된 공식 클라이언트 SDK입니다.

이 SDK를 사용하면 복잡한 HTTP 요청을 직접 작성할 필요 없이, 타입 안전한 인터페이스를 통해 학생, 동아리, 프로젝트, NEIS 데이터를 조회하고 학생, 동아리, 프로젝트 데이터를 생성, 수정할 수 있습니다.

### 주요 특징

| 특징                  | 설명                                                                   |
|---------------------|----------------------------------------------------------------------|
| **타입 안전성**          | 강타입 시스템으로 컴파일 타임에 오류를 검출하여 런타임 에러를 방지합니다.                            |
| **Kotlin 완벽 호환**    | Java와 Kotlin 프로젝트 모두에서 자연스럽게 사용할 수 있습니다.                             |
| **빌더 패턴**           | 직관적이고 유연한 API 요청 구성을 지원합니다.                                          |
| **자동 리소스 관리**       | `AutoCloseable` 구현으로 리소스 누수를 자동으로 방지합니다.                             |
| **구체적인 예외 처리**      | HTTP 상태 코드별 전용 예외 타입을 제공하여 정확한 에러 핸들링이 가능합니다.                        |
| **검증된 HTTP 클라이언트**  | OkHttp 기반으로 안정적이고 효율적인 통신을 보장합니다.                                    |
| **서버 타입 공유**       | 응답 모델은 서버가 배포하는 `datagsm-shared` 타입을 사용하며 SDK 의존성으로 함께 내려받습니다.   |

## API 레퍼런스

SDK는 다음과 같은 API 클라이언트를 제공합니다. 쓰기 메서드를 쓰려면 API 키에 해당 쓰기 권한 범위(`student:write`, `club:write`, `project:write`)가 있어야 합니다. 이 범위는 관리자 계정만 발급할 수 있습니다.

### 학생 API

**`client.students()`** - 학생 데이터 조회 및 관리

| 메서드                          | 설명                                | 반환 타입               |
|------------------------------|-----------------------------------|---------------------|
| `getStudents(request)`       | 조건에 맞는 학생 목록 조회                   | `StudentListResDto` |
| `getStudent(id)`             | 학생 단건 조회. 졸업생, 자퇴생 포함, 없으면 `null` | `StudentResDto`     |
| `createStudent(request)`     | 학생 생성                             | `StudentResDto`     |
| `updateStudent(id, request)` | 학생 수정 (전체 교체)                     | `StudentResDto`     |

<CodeTabs>
  <CodeTab label="Java" language="java" code={`// 학생 목록 조회
StudentListResDto students = client.students().getStudents(request);

// 특정 학생 조회
StudentResDto student = client.students().getStudent(1L);`} />

  <CodeTab label="Kotlin" language="kotlin" code={`// 학생 목록 조회
val students = client.students().getStudents(request)

// 특정 학생 조회
val student = client.students().getStudent(1L)`} />

</CodeTabs>

`StudentRequest`의 필터는 체이닝 메서드로 지정합니다. 기본값은 `page` 0, `size` 300, `sortDirection` `ASC`이며 `size`는 최대 1000입니다.

| 메서드                                    | 설명                             |
|----------------------------------------|--------------------------------|
| `studentId(Long)`                      | 학생 ID                          |
| `name(String)`, `email(String)`        | 이름, 이메일                        |
| `grade(Integer)`, `classNum(Integer)`, `number(Integer)` | 학년, 반, 번호    |
| `sex(Sex)`, `role(StudentRole)`        | 성별, 역할                         |
| `dormitoryRoom(Integer)`               | 기숙사 호실                         |
| `specialty(String)`, `major(Major)`    | 전공, 학과                         |
| `githubId(String)`                     | GitHub 아이디 (부분 일치)             |
| `enrollmentFilter(EnrollmentFilter)`   | 재학 상태 필터                       |
| `page(Integer)`, `size(Integer)`       | 페이지 번호, 페이지 크기                 |
| `sortBy(StudentSortBy)`, `sortDirection(SortDirection)` | 정렬 기준, 정렬 방향 |

#### 재학 상태 필터링 (`EnrollmentFilter`)

`StudentRequest`의 재학 상태 필터링은 `EnrollmentFilter` Type-State DSL을 통해 구성합니다. 우선순위를 위반하는 파라미터 조합(예: `onlyEnrolled=true` + `includeGraduates=true`)은 타입 시스템에 의해 **컴파일 타임에 방지**됩니다.

| 생성 방법                           | 설명                                          |
|-----------------------------------|---------------------------------------------|
| `EnrollmentFilter.onlyEnrolled()` | 재학생만 조회. `includeGraduates` / `includeWithdrawn` 사용 불가 |
| `EnrollmentFilter.detailed()`     | 졸업생·자퇴생 포함 여부를 세밀하게 설정                      |
| _(필터 미설정)_                      | 서버 기본값 사용                                   |

<CodeTabs>
  <CodeTab label="Java" language="java" code={`import team.themoment.datagsm.sdk.openapi.model.EnrollmentFilter;

// 재학생만 조회
StudentApi.StudentRequest onlyEnrolledRequest = new StudentApi.StudentRequest()
    .enrollmentFilter(EnrollmentFilter.onlyEnrolled());

// 졸업생 포함 조회
StudentApi.StudentRequest includeGraduatesRequest = new StudentApi.StudentRequest()
    .enrollmentFilter(EnrollmentFilter.detailed().includeGraduates(true));

// 자퇴생 포함 조회
StudentApi.StudentRequest includeWithdrawnRequest = new StudentApi.StudentRequest()
    .enrollmentFilter(EnrollmentFilter.detailed().includeWithdrawn(true));

// 서버 기본값 사용 (파라미터 미전송)
StudentApi.StudentRequest defaultRequest = new StudentApi.StudentRequest();`} />

  <CodeTab label="Kotlin" language="kotlin" code={`import team.themoment.datagsm.sdk.openapi.model.EnrollmentFilter

// 재학생만 조회
val onlyEnrolledRequest = StudentApi.StudentRequest()
    .enrollmentFilter(EnrollmentFilter.onlyEnrolled())

// 졸업생 포함 조회
val includeGraduatesRequest = StudentApi.StudentRequest()
    .enrollmentFilter(EnrollmentFilter.detailed().includeGraduates(true))

// 자퇴생 포함 조회
val includeWithdrawnRequest = StudentApi.StudentRequest()
    .enrollmentFilter(EnrollmentFilter.detailed().includeWithdrawn(true))

// 서버 기본값 사용 (파라미터 미전송)
val defaultRequest = StudentApi.StudentRequest()`} />

</CodeTabs>

**`client.projects()`** - 프로젝트 데이터 조회 및 관리

|--------------------------------|----------------------------------------|---------------------|
| `getProjects(request)`         | 조건에 맞는 프로젝트 목록 조회                      | `ProjectListResDto` |

`ProjectRequest`의 필터는 `projectId`, `projectName`, `clubId`, `status`, `category`, `page`, `size`, `sortBy`, `sortDirection`입니다. 기본값은 `page` 0, `size` 100, `sortDirection` `ASC`입니다. `status`를 지정하지 않으면 서버 기본값에 따라 `ACTIVE` 프로젝트만 조회됩니다. `category`는 해당 카테고리를 포함하는 프로젝트를 찾으며 `ProjectCategory` 또는 이름 문자열을 받습니다.

### NEIS API

**`client.neis()`** - 나이스 교육정보시스템 데이터 조회

| 메서드                      | 설명         | 반환 타입             |
|--------------------------|------------|-------------------|
| `getMeals(request)`      | 급식 데이터 조회  | `MealResDto`      |
| `getSchedules(request)`  | 학사일정 조회    | `ScheduleResDto`  |
| `getTimetables(request)` | 시간표 데이터 조회 | `TimetableResDto` |

<CodeTabs>
  <CodeTab label="Java" language="java" code={`// 급식 데이터 조회
MealResDto meals = client.neis().getMeals(
    new NeisApi.MealRequest().date(LocalDate.now()));

// 학사일정 조회
ScheduleResDto schedules = client.neis().getSchedules(
    new NeisApi.ScheduleRequest()
        .fromDate(LocalDate.of(2026, 3, 1))
        .toDate(LocalDate.of(2026, 3, 31)));

// 시간표 조회 (학년, 반)
TimetableResDto timetables = client.neis().getTimetables(
    new NeisApi.TimetableRequest(1, 1).date(LocalDate.now()));`} />

  <CodeTab label="Kotlin" language="kotlin" code={`// 급식 데이터 조회
val meals = client.neis().getMeals(
    NeisApi.MealRequest().date(LocalDate.now()))

// 학사일정 조회
val schedules = client.neis().getSchedules(
    NeisApi.ScheduleRequest()
        .fromDate(LocalDate.of(2026, 3, 1))
        .toDate(LocalDate.of(2026, 3, 31)))

// 시간표 조회 (학년, 반)
val timetables = client.neis().getTimetables(
    NeisApi.TimetableRequest(1, 1).date(LocalDate.now()))`} />

</CodeTabs>

세 요청 모두 `date(LocalDate)` 또는 `fromDate(LocalDate)`, `toDate(LocalDate)`로 날짜를 지정합니다. `date`와 기간은 함께 쓸 수 없고 기간은 최대 365일입니다.

- `TimetableRequest`는 학년과 반이 필수이고 날짜 조건도 하나 이상 필요합니다. 조건이 맞지 않으면 요청을 보내기 전에 `IllegalArgumentException`이 발생합니다.
- `MealRequest`, `ScheduleRequest`는 날짜 조건을 생략할 수 있습니다. 이때 서버에 저장된 전체 데이터가 반환됩니다.
- 학사일정의 `scheduleId` 형식이 바뀌어 이전에 저장한 ID는 조회되지 않습니다. 자세한 내용은 [변경 사항 및 마이그레이션](/migration)을 참고하세요.

### 쓰기 API

요청 객체는 `team.themoment.datagsm.sdk.openapi.model.request` 패키지에 있습니다. 필수 값은 생성자로 받고 선택 값은 체이닝 메서드로 지정합니다. `null`인 필드는 요청 본문에서 생략됩니다.

<CodeTabs>
  <CodeTab label="Java" language="java" code={`import java.util.List;

import team.themoment.datagsm.shared.domain.club.dto.response.ClubResDto;
import team.themoment.datagsm.shared.domain.club.entity.constant.*;
import team.themoment.datagsm.shared.domain.project.dto.response.ProjectResDto;

### 응답 모델

응답 모델은 `team.themoment.datagsm.shared.domain` 패키지의 타입입니다. 필드는 [HTTP API 문서](/api/http)의 응답과 같고 Java에서는 getter로, Kotlin에서는 프로퍼티로 읽습니다.

| API | 목록 응답 | 항목 |
| --- | --- | --- |
| 학생 | `student.dto.response.StudentListResDto` (`getStudents()`) | `StudentResDto` |
| 동아리 | `club.dto.response.ClubListResDto` (`getClubs()`) | `ClubResDto` |
| 프로젝트 | `project.dto.response.ProjectListResDto` (`getProjects()`) | `ProjectResDto` |
| 급식 | `neis.dto.meal.response.MealResDto` (`getMeals()`) | `MealInfoResDto` |
| 학사일정 | `neis.dto.schedule.response.ScheduleResDto` (`getSchedules()`) | `ScheduleInfoResDto` |
| 시간표 | `neis.dto.timetable.response.TimetableResDto` (`getTimetables()`) | `TimetableInfoResDto` |

- 학생, 동아리, 프로젝트 목록 응답에는 `getTotalPages()`, `getTotalElements()`도 있습니다.
- 없는 값은 `null`입니다. `Optional`을 쓰지 않으므로 `getStudentNumber()`, `getMajor()` 같은 값은 `null`을 확인하고 사용하세요.
- 프로젝트의 `getCategories()`는 `List<ProjectCategory>`입니다. 미분류이면 빈 목록입니다.
- NEIS 날짜 필드는 `kotlinx.datetime.LocalDate` 타입입니다.
- 서버에 새 enum 값이 추가되면 nullable 필드는 `null`로 읽고 목록 안의 값은 제외합니다.

## 예외 처리

SDK는 HTTP 상태 코드별로 구체적인 예외 타입을 제공합니다.

### 예외 종류

| 예외 타입                   | HTTP 상태 | 발생 상황               | 권장 처리 방법                        |
|-------------------------|---------|---------------------|---------------------------------|
| `UnauthorizedException` | 401     | API 키 유효하지 않음 또는 만료 | API 키 갱신 또는 재발급                 |
| `ForbiddenException`    | 403     | 필요한 권한 범위 부족        | 권한 범위 확인 및 요청                   |
| `BadRequestException`   | 400     | 잘못된 요청 파라미터         | 요청 파라미터 검증                      |
| `NotFoundException`     | 404     | 리소스를 찾을 수 없음        | ID 확인                           |
| `ConflictException`     | 409     | 이름, 이메일 등 중복        | 입력값 확인                          |
| `RateLimitException`    | 429     | Rate limit 초과       | 재시도 로직 구현 (Exponential Backoff) |
| `ServerErrorException`  | 500, 502, 503, 504 | 서버 오류  | 잠시 후 재시도 또는 관리자 문의              |
| `DataGsmException`      | 기타      | 기타 API 오류. 모든 예외의 부모 클래스 | `getStatusCode()`와 에러 메시지 확인    |

### 자주 발생하는 문제

#### 401 Unauthorized 오류

**원인**: API 키가 유효하지 않거나 만료됨

**해결 방법**:

- API 키가 올바르게 설정되었는지 확인
- API 키가 만료되지 않았는지 확인
- 필요시 새로운 API 키 발급

#### 403 Forbidden 오류

**원인**: 요청한 API에 대한 권한 범위 부족

**해결 방법**:

- API 키의 권한 범위 확인 (`student:read`, `student:write` 등)
- 쓰기 권한 범위는 관리자 계정만 발급할 수 있습니다.
- 권한 범위 추가가 필요한 경우 관리자에게 문의

## 마이그레이션

서버 쪽 변경은 [변경 사항 및 마이그레이션](/migration)을 참고하십시오. 아래 표의 Deprecated 항목은 동작하지만 제거 일정은 미정입니다.

### 현재 Deprecated 항목

- **Deprecated**: `DataGsmClient` → `DataGsmOpenApiClient`
  - 영향: 계속 동작합니다.
  - 대응: 클래스를 교체합니다. 메서드 이름은 같습니다.
- **Deprecated**: `ClubRequest.status()`, `getStatus()` → `clubStatus()`, `getClubStatus()`
  - 영향: 계속 동작합니다.
  - 대응: 메서드 이름을 바꿉니다.

### 3.0.0 → 3.0.1

코드는 그대로이고 의존성 좌표만 바뀌었습니다. `import`는 바꾸지 않습니다.

- **Breaking**: `team.themoment.datagsm.sdk:openapi` (GitHub Packages) → `io.github.themoment-team:datagsm-openapi-sdk-java` (Maven Central)
  - 영향: 좌표를 바꾸지 않으면 새 버전을 받을 수 없습니다.
  - 대응: 의존성 좌표를 바꿉니다. GitHub Packages 저장소 설정과 `gpr.user`, `gpr.token` 같은 인증 정보를 지웁니다.

### 2.x → 3.0

- **Breaking**: 목록 응답이 배열(`XxxResDto[]`) → `List<XxxResDto>`
  - 영향: 컴파일 오류가 납니다.
  - 대응: 배열 접근을 `List` 메서드로 바꿉니다.
- **동작 변경**: 404를 `DataGsmException`으로 처리 → `NotFoundException`, 409는 `ConflictException`
  - 영향: 기존 `catch (DataGsmException)`은 그대로 동작합니다.
  - 대응: 필요하면 전용 예외로 나눕니다.
- **동작 변경**: 동아리 상태 필터가 `status` 쿼리로 전송되어 서버에서 무시됨 → `clubStatus` 쿼리로 전송
  - 영향: 필터가 실제로 적용됩니다.
  - 대응: `clubStatus()`로 바꾸고 결과를 확인합니다.
- **동작 변경**: `getStudent`는 재학생 위주로 조회, `getProject`는 `ACTIVE`만 조회 → `getStudent`는 졸업생, 자퇴생 포함, `getProject`는 `ENDED`까지 조회
  - 영향: 이전에 `null`이던 ID가 값을 반환할 수 있습니다.
  - 대응: 호출부의 가정을 확인합니다.
- **동작 변경**: 날짜 조건을 서버가 검증 → `getTimetables`가 요청 전에 검증
  - 영향: 조건이 맞지 않으면 `IllegalArgumentException`이 발생합니다.
  - 대응: 날짜 조건을 지정합니다.
- **동작 변경**: `HttpClient`는 `get`만 구현 → `post`, `put`, `delete` 기본 메서드 추가
  - 영향: 읽기 전용 커스텀 구현은 그대로 동작합니다.
  - 대응: 쓰기 API를 쓰려면 직접 구현합니다.
- **추가**: 쓰기 API, `ProjectRequest.category()`, `ProjectCategory`
  - 영향: 없습니다.
  - 대응: 필요하면 사용합니다.

### 1.x → 2.0

- **Breaking**: Java 13 → Java 17
  - 영향: Java 16 이하에서는 쓸 수 없습니다.
  - 대응: JDK를 올립니다.
- **Breaking**: `sdk.openapi.model`의 `Student`, `StudentResponse`, `Club`, `ClubDetail`, `Project`, `Meal` 등 → `datagsm-shared`의 `StudentResDto`, `StudentListResDto`, `ClubResDto`, `ProjectResDto`, `MealInfoResDto` 등
  - 영향: 컴파일 오류가 납니다.
  - 대응: `import`와 타입을 바꿉니다. `EnrollmentFilter`, `SortDirection`은 그대로입니다.
- **Breaking**: `getStudentNumber()` 등이 `Optional<T>` 반환 → 값 또는 `null` 반환
  - 영향: `.orElse()`, `.isPresent()`에서 컴파일 오류가 납니다.
  - 대응: `null` 확인으로 바꿉니다.
- **Breaking**: `getMeals`, `getSchedules`, `getTimetables`가 `List` 반환 → `MealResDto`, `ScheduleResDto`, `TimetableResDto` 반환
  - 영향: 컴파일 오류가 납니다.
  - 대응: `getMeals()`, `getSchedules()`, `getTimetables()`로 목록을 꺼냅니다.
