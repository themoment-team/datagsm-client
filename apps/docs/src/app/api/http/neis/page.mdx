# NEIS 데이터 OpenAPI

## 개요

NEIS 데이터 OpenAPI는 나이스(NEIS)에서 제공하는 급식 데이터, 학사일정 데이터, 시간표 데이터를 간단한 HTTP 요청을 통하여 서비스에 통합할 수 있도록 돕습니다. 해당 REST API를 호출하여 기본적인 급식, 학사일정, 시간표 데이터를 획득할 수 있습니다.

## 제공하는 API

NEIS 데이터 OpenAPI는 다음과 같은 세 가지 주요 API를 제공합니다:

- **[급식 데이터 API](/api/http/neis/meals)**: 학교의 급식 메뉴, 알레르기 데이터, 영양 데이터 등을 조회할 수 있습니다.
- **[학사일정 데이터 API](/api/http/neis/schedules)**: 학교의 학사일정, 행사 데이터 등을 조회할 수 있습니다.
- **[시간표 데이터 API](/api/http/neis/timetables)**: 학년·반별 교시 및 과목 시간표를 조회할 수 있습니다.

## 인증

모든 API 요청은 HTTP 헤더에 API 키를 포함해야 합니다.

```http
X-API-KEY: your-api-key-here
```

API 키는 UUID 형식이며, 만료되거나 유효하지 않은 키를 사용할 경우 `401 Unauthorized` 응답을 받게 됩니다.

## 권한 범위

`neis:read` 또는 `neis:*` 권한 범위가 필요합니다.

## 공통 사항

### 날짜 형식

모든 날짜 파라미터는 ISO 8601 형식(`YYYY-MM-DD`)을 따릅니다.

**예시**: `2025-12-15`

### 날짜 파라미터 사용 규칙

- `date`: 특정 날짜의 데이터만 조회
- `fromDate`와 `toDate`: 기간 범위 내의 데이터 조회
- `fromDate`만 보내면 그 날짜부터 1년 뒤까지, `toDate`만 보내면 그 날짜의 1년 전부터 조회
- `date`와 `fromDate`/`toDate`는 동시에 사용할 수 없습니다.
- `fromDate`는 `toDate`보다 늦을 수 없고, 최대 조회 기간은 365일입니다.
- 급식과 학사일정은 파라미터를 생략하면 저장된 전체 데이터를 반환합니다. 시간표는 날짜 파라미터가 필수입니다.

### 데이터 범위

DataGSM은 NEIS 데이터를 매일 새벽에 동기화하며, 현재 학년도(3월 1일부터 다음 해 2월 말까지)의 데이터만 제공합니다. 지난 학년도 날짜를 조회하면 빈 목록이 반환될 수 있습니다.

### 응답 형식

모든 성공 응답은 다음과 같은 공통 구조로 반환되며, `data` 내부 구조는 API별로 다릅니다:

| 필드        | 타입       | 설명          | 예시    |
|-----------|----------|-------------|-------|
| `status`  | `String` | HTTP 상태 메시지 | `200 OK` |
| `code`    | `Int`    | HTTP 상태 코드  | `200` |
| `message` | `String` | 응답 메시지      | `OK`  |
| `data`    | `Object` | API별 데이터 객체 | -     |

## 공통 오류 응답

| 상태 코드                   | 설명                  |
|-------------------------|---------------------|
| `401 Unauthorized`      | API 키가 유효하지 않거나 만료됨 |
| `403 Forbidden`         | 권한 범위 부족            |
| `429 Too Many Requests` | 단위 시간에 너무 많은 요청량 발생 |
| `400 Bad Request`       | 잘못된 요청 파라미터         |
