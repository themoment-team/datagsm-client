# 사용자 데이터 조회

### 엔드포인트

```http
GET /userinfo
```

### 설명

Access Token을 사용하여 인증된 사용자의 데이터를 조회합니다.
이 엔드포인트는 사용자의 기본 데이터를 반환하고, 토큰의 권한 범위에 따라 학생 또는 선생님 상세 데이터, 동아리, 프로젝트를 채워 반환합니다.

경로에 `/v1` 접두어가 없고, 응답은 공통 응답 구조로 감싸지 않은 JSON 객체입니다.

### 인증

이 엔드포인트는 `Authorization` 헤더에 Bearer Token을 포함해야 합니다.

```http
Authorization: Bearer {accessToken}
```

### 요청 파라미터

요청 파라미터는 없습니다. Access Token만 필요합니다.

### 필요한 권한 범위

호출에는 `account_read` 또는 Deprecated인 `self_read`가 필요합니다. `student_read`만 있으면 `403 Forbidden`입니다.

| 응답 필드 | 값이 채워지는 조건 | 조건을 만족하지 않을 때 |
|---|---|---|
| 계정 기본 필드 | 호출 가능한 모든 토큰 | - |
| `student`, `teacher` | `student_read` 또는 `self_read` | `null` |
| `student.majorClub`, `student.autonomousClub` | `club_read` 또는 `self_read` | `null` |
| `clubs` | `club_read` | 빈 배열 |
| `projects` | `project_read` | 빈 배열 |

범위별 설명과 `self_read` 전환 방법은 [권한 범위](/oauth/scopes)를 참고하세요.

### 응답 필드

#### 사용자 기본 데이터

| 필드 | 타입 | 설명 | 예시 |
|---|---|---|---|
| `sub` | `String` | OIDC 사용자 식별자. `email`과 같은 값이며 `id_token`의 `sub`와 일치합니다 | `student@gsm.hs.kr` |
| `id` | `Long` | 사용자 고유 ID | `1` |
| `email` | `String` | 사용자 이메일 주소 | `student@gsm.hs.kr` |
| `role` | `String` | 사용자 역할 (`ROOT`, `ADMIN`, `USER`) | `USER` |
| `status` | `String` | 계정 상태 (`PENDING`, `ACTIVE`). 선생님 계정은 어드민 승인 전까지 `PENDING`으로 유지됩니다 | `ACTIVE` |
| `objectType` | `String?` | 연결된 대상 종류 (`STUDENT`, `TEACHER`). 연결된 대상이 없으면 `null` | `STUDENT` |
| `isStudent` | `Boolean` | **(Deprecated)** 학생 계정 여부. `objectType == STUDENT`의 파생값입니다. 제거 일정은 미정이며, 신규 연동은 `objectType`을 사용하세요 | `true` |
| `student` | `Object?` | 학생 상세 데이터. `student_read` 또는 `self_read`가 있고 학생 계정일 때만 제공 | - |
| `teacher` | `Object?` | 선생님 상세 데이터. `student_read` 또는 `self_read`가 있고 선생님 계정일 때만 제공 | - |
| `clubs` | `Array` | 소속 동아리 목록. `club_read`가 없으면 빈 배열 | - |
| `projects` | `Array` | 참여 프로젝트 목록. `project_read`가 없으면 빈 배열 | - |

### 오류 응답

| 상태 코드 | 설명 | 원인 |
|---|---|---|
| `401 Unauthorized` | 인증 실패 | 토큰 없음, 잘못된 `Authorization` 헤더, 형식이나 서명이 잘못된 토큰, 만료된 토큰 |
| `403 Forbidden` | 권한 범위 부족 | 토큰에 `account_read`와 `self_read`가 모두 없음 |
| `404 Not Found` | 리소스를 찾을 수 없음 | 토큰의 사용자 계정을 찾을 수 없음. Client Credentials 토큰은 사용자가 없어 이 엔드포인트에 사용할 수 없습니다 |
| `429 Too Many Requests` | 요청 한도 초과 | 클라이언트 기준 분당 300회 초과. `Retry-After` 헤더의 초만큼 기다린 뒤 다시 시도하세요 |

```json

```

`message`는 원인에 따라 달라지므로 분기에는 HTTP 상태 코드를 사용하세요.

import java.net.URI;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.List;

public class UserInfoService {
    private static final HttpClient client = HttpClient.newHttpClient();
    private static final ObjectMapper mapper = new ObjectMapper();

    public static UserInfo getUserInfo(String accessToken) throws Exception {
        // HTTP 요청 생성
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://oauth.resource.datagsm.kr/userinfo"))
            .header("Authorization", "Bearer " + accessToken)
            .GET()
            .build();

        // 요청 전송
        HttpResponse<String> response = client.send(
            request,
            HttpResponse.BodyHandlers.ofString()
        );

        // 응답 처리
        if (response.statusCode() != 200) {
            throw new RuntimeException("Failed to get user info: " + response.body());
        }

        return mapper.readValue(response.body(), UserInfo.class);
    }

    public static class UserInfo {
        public String sub;
        public Long id;
        public String email;
        public String role;
        public String status;

### 보안 주의사항

#### Access Token 보호

- Access Token은 사용자의 개인정보에 접근할 수 있는 권한을 부여합니다.
- Access Token을 안전하게 저장하고, HTTPS를 통해서만 전송하세요.
- Access Token이 탈취되면 공격자가 사용자 데이터를 조회할 수 있습니다.

#### 토큰 만료 처리

- Access Token은 1시간 후 만료됩니다.
- 만료 시 `401 Unauthorized` 오류가 발생하며, Refresh Token으로 갱신해야 합니다.

```javascript
async function getUserInfoWithRetry(accessToken, refreshToken) {
  try {
    return await getUserInfo(accessToken);
  } catch (error) {
    if (error.status === 401) {
      // Access Token 갱신
      const tokens = await refreshAccessToken(refreshToken, 'your-client-id');
      // 새 토큰으로 재시도
      return await getUserInfo(tokens.accessToken);
    }
    throw error;
  }
}
```
